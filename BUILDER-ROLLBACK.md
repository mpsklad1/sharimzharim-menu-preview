# Тестовый конструктор блюда — 10 октября 2026

## Что изменено

Два входа в меню: «Приготовь бургер», «Приготовь шаурму».
Вокруг персонажа находятся доступные допы выбранной основы из `/api/catalog`.
Нажатие добавляет ингредиент и анимирует его движение в блюдо; повторное нажатие убирает его.
Основа остаётся реальным блюдом меню: её состав раскрывается под конструктором.
Ограничения групп, исключения из состава, цена и XL передаются в обычную корзину.
«Заказать» открывает корзину. Оформление заказа остаётся демо.
Режим уменьшенного движения отключает перемещение ингредиентов.

База данных, цены, отзывы, авторизация и бот не изменяются этим выпуском.

## Откат исходников

В чистом рабочем дереве репозитория меню:

```sh
git revert release/meal-builder-20261010
git push origin main
```

Это создаёт обратный коммит, сохраняя историю. Не использовать `reset --hard`.
После изменений других разработчиков Git может запросить разрешение конфликтов.
Для публикации на VPS требуется отдельно выложить возвращённые `app.js` и `index.html`.

## Немедленный откат сайта на VPS

На сервере сохранён файл:
`/opt/sharim/backups/meal-builder-20261010/rollback.sh`.

```sh
ssh stiralki 'sh /opt/sharim/backups/meal-builder-20261010/rollback.sh'
```

Скрипт проверяет контрольные суммы текущих `app.js` и `index.html`.
Если после выпуска их изменил другой разработчик, скрипт остановится.
Он возвращает только эти два файла из сохранённой версии и не затрагивает серверную базу.
Новые файлы конструктора остаются на диске, но старая страница их не подключает.
Пользователю нужно переоткрыть мини-приложение или обновить страницу.

Полная копия фронтенда до публикации:
`/opt/sharim/backups/meal-builder-20261010/menu-before.tar.gz`.
